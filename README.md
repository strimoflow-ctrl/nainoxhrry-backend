# Naino X Hrry Backend

High-speed streaming & API proxy server for the Naino X Hrry Flutter Application.

## Supported Platforms
- Khan GS Research
- CareerWill
- Rozgar with Ankit (RWA)
- Selection Way
- Study IQ
- Next Toppers
- Testbook V2 & Testbook Pro

## Deployment
Can be deployed anywhere with Node.js 18+ or Docker (Render, Koyeb, Railway, VPS).

### Run Locally:
```bash
npm start
```
Default Port: `4000` (configurable via `PORT` environment variable).
